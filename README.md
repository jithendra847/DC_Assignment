# Data Communication Assignment

A beginner-friendly Python project for exploring digital signal encoding and decoding. The project will be built in small milestones, with each milestone kept in this folder.

## Requirements

- Python 3.10 or newer
- NumPy
- Matplotlib
- Pillow

Install the dependencies with:

```powershell
python -m pip install -r requirements.txt
```

## Planned milestones

1. Project setup
2. Digital data generation
3. Longest palindromic substring detection
4. Line coding: NRZ-L, NRZ-I, Manchester, Differential Manchester, and AMI
5. B8ZS and HDB3 scrambling
6. PCM and Delta Modulation
7. Signal plotting
8. Image-based decoding
9. Interactive program
10. Automated tests
11. Specification report
12. Integration and documentation updates

The algorithms and application files will be added in their respective milestones.

## Running the project

The interactive program will be started with:

```powershell
python main.py
```

Tests will be run with:

```powershell
python -m unittest
```
